# 组件来源

PaperPilot 从用户授权的 Traceify 2026-11-09 交接包选择性迁移纯数据操作、来源映射、模块边界、三方比较和画布手势。graph.js、modules.js、merge.js、canvas.js 按本项目集成需求适配。

canvas.js 的底层交互原始迁移来源为用户所有的 AgentLoop 恢复包0.3.41，提交6af9320。原交接包SHA256为5912deac02b0a920ee3b1ada85c147fcea2bf8f02c64429d1ce0f98648d07207。

保留原交接包的 Sleek MIT 许可于 Sleek-LICENSE。原skill和图谱契约继续位于 paperpilot/skills/traceify/。PaperPilot的界面、存储会话及宿主流程由本项目维护。
